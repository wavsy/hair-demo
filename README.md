# ONDÉ — демо на салон за красота

Демонстрационен сайт за **измислен** салон за красота в София. Салонът не
съществува. Служи за показване пред потенциални клиенти от бранша, за да видят
какво получават, преди да подпишем договор.

Сайтът е `noindex`, за да не влезе измисленият салон в Google.

## Логиката: салонът са хората

Началната страница не е начална страница на салон. Тя е **пет лица на цял
екран** и нищо друго — първото решение на посетителя е *при кого*, не *каква
услуга*. Всичко останало живее в страницата на един човек: неговите работи,
неговите цени, неговият календар, отзивите за него.

Това е обратното на обичайния салонен сайт, където услугите са в средата, а
хората са лента някъде долу. Направено е така, защото в този бранш марката е
около майстора: клиентът се връща при човек, а отзивите хвалят поименно.

| Адрес | Какво е |
|---|---|
| `/` · `/en` | Петте лица |
| `/maistori/<име>` · `/en/stylists/<name>` | Един човек: работи, цени, календар, отзиви |
| `/kursove` · `/en/courses` | Трите курса с приеми и записване |
| `/salona` · `/en/the-salon` | Работно време, телефон, карта |
| `/qr` | QR код за срещи |

## Правила, които кодът пази

Всяко от тях е тест, не обещание:

- **Никой не се предлага за работа, която не върши.** Ирина казва в своя текст,
  че не подстригва — ако някой ѝ сложи подстригване, тестът пада.
- **Всяка цена има източник.** Всеки ред в `lib/pricing.ts` носи коментар от кой
  публикуван софийски ценоразпис идва.
- **Всяка цена се предлага от някого.** Ред без майстор означава цена, която не
  може да се запази.
- **Всеки надпис под снимка описва снимката.** Затова се преглеждат на око.
- **Приемите за курсове не остаряват** — смятат се от днешната дата.
- **В неделя салонът почива** и графикът не предлага нито един час.

## Работа по проекта

```bash
npm install
npm run dev          # http://localhost:3000

npm test             # 31 модулни теста
npm run build && npm start
npm run test:e2e     # 13 теста в браузър, срещу вдигнат сървър
npm run photos       # сваля снимките CC0
```

`npm run test:e2e` ползва вече инсталиран Chrome — не сваля браузър. Срещу
живия адрес: `E2E_URL=https://… npm run test:e2e`.

Ако добавите текст само на единия език, `npm test` пада — речниците се сравняват
ключ по ключ.

## Къде какво стои

```
app/            маршрутите, по един тънък файл на страница и език
components/
  Faces.tsx         началната страница
  MasterPage.tsx    страницата на един човек
  MasterBooking.tsx неговият календар и записване
  Chrome.tsx        лентата горе и редът долу
lib/
  masters.ts    петимата: снимки, услуги, текстове на двата езика
  pricing.ts    цените, с източник на всеки ред
  courses.ts    приемите, смятани от днешната дата
  slots.ts      работното време и графикът на всеки майстор
  routes.ts     всички адреси на двата езика
  content.ts    общите текстове, bg и en с еднаква форма
scripts/        сваляне на снимките
tests/          модулни (.test.mts) и браузърни (e2e.mjs)
```

## Снимки

Избраните снимки **са в хранилището**. Извън него остават резервите в
`public/images/_alt/`.

```bash
npm run photos              # пълни празните места
npm run photos -- --force   # тегли наново всички
```

Скриптът тегли CC0 от Openverse (`source=stocksnap`) и записва
`public/images/CREDITS.md` с автор и източник. Ключът за Openverse стои в
`.env.local`, извън хранилището — вади се с един POST към
`api.openverse.org/v1/auth_tokens/register/`.

**Ако смените снимка, изтрийте `.next/cache/images`** — иначе Next продължава да
показва старата.
