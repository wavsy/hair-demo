# ONDÉ — демо на салон за красота

Демонстрационен сайт за **измислен** салон за красота в София. Салонът не
съществува. Служи за показване пред потенциални клиенти от бранша, за да видят
какво получават, преди да подпишем договор.

Сайтът е `noindex`, за да не влезе измисленият салон в Google.

## Състояние

**Готово за показване.**

- [x] Марка: име, лого, тъмна редакторска палитра
- [x] Съдържание на български и английски
- [x] Четири направления с ценоразписи · курсове · галерия · екип
- [x] Записване: направление → майстор → ден и час
- [x] Снимки CC0, свалени и избрани на око
- [x] Качване на кратък адрес и `/qr` за срещи

Проверено на 21.09.2026 г.: 45 модулни теста, 14 браузърни, чист билд,
LCP 784 ms на бавен телефон, CLS 0.

## Какво показва демото

Три решения, взети след оглед на бранша. Кое откъде идва е в
[`DECISIONS.md`](DECISIONS.md).

1. **Услугите не се изсипват на страницата.** Четири направления като карти;
   ценоразписът се отваря само за това, което сте избрали, и вътре се маркират
   позиции, които се събират в сметка.
2. **Сайтът е построен около майсторите.** Петима души поименно, под всеки стои
   „Запазете час при…“, а изборът на майстор стеснява свободните часове до
   неговия график.
3. **Курсовете са отделна продаваща секция** — програма, такса, документ,
   следващи приеми със свободни места и записване онлайн.

Плюс: калкулатор в евро с левова равностойност, `.ics` файл за календара,
правилов асистент без външен модел, две езикови версии.

## Работа по проекта

```bash
npm install
npm run dev          # http://localhost:3000

npm test             # модулни тестове
npm run build && npm start
npm run test:e2e     # в браузър, срещу вдигнат сървър
npm run photos       # сваля снимките CC0
```

`npm run test:e2e` ползва вече инсталиран Chrome — не сваля браузър. Ако той не
е на стандартното място, подайте пътя:

```bash
CHROME_PATH=/path/to/chrome npm run test:e2e
```

Ако добавите текст само на единия език, `npm test` пада — речниците се сравняват
ключ по ключ. Същият тест пази и ценоразписа: всяка позиция в `lib/pricing.ts`
трябва да има заглавие и на двата езика.

## Снимки

Избраните снимки **са в хранилището** — живият сайт не зависи от това някой да
ги е теглил. Извън него остават само резервите в `public/images/_alt/`.

Нови се вадят с:

```bash
npm run photos          # пълни само празните места
npm run photos -- --force   # тегли наново всички
```

Скриптът тегли CC0 от Openverse (`source=stocksnap`), слага по един избор в
`public/images/` и по пет резерви в `public/images/_alt/`, защото половината не
стават и изборът е на око — смяната после е едно `cp`. Накрая записва
`public/images/CREDITS.md` с автор и източник за всяка снимка.

**Ключ.** Анонимните заявки към Openverse свършват след няколко търсения, а едно
пълнене е четиринайсет. Безплатен ключ се вади с една команда:

```bash
curl -X POST https://api.openverse.org/v1/auth_tokens/register/ \
  -H 'Content-Type: application/json' \
  -d '{"name":"...","description":"...","email":"..."}'
```

Двойката отива в `.env.local`, която не влиза в хранилището. Без ключ скриптът
пак работи, но бавно и докъдето стигне безплатната квота.

**Ако смените снимка, изтрийте `.next/cache/images`** — иначе Next продължава да
показва старата и се чудите защо.

## Къде какво стои

```
app/            / (bg) · /en · /qr · layout и глобалните стилове
components/     секциите на страницата, по една на файл
lib/
  content.ts    целият текст, bg и en, с еднаква форма
  pricing.ts    цените, с коментар за източника на всеки ред
  courses.ts    приемите за курсовете, изчислени от днешната дата
  slots.ts      работното време и графиците на майсторите
  assistant.ts  правилата на асистента
scripts/        сваляне на снимките
tests/          модулни тестове и браузърни проверки
```

## Правила, които кодът пази

- **Цените имат източник.** Всеки ред в `lib/pricing.ts` носи коментар от кой
  публикуван ценоразпис идва. Нищо не се измисля.
- **Нито един майстор не се предлага за нещо, което не работи.** Тестът пада,
  ако направление остане без човек или човек — без направление.
- **Приемите за курсове не остаряват.** Изчисляват се от днешната дата, затова
  на екрана никога не стои дата отпреди месец.
- **В неделя салонът почива** — и графикът не предлага нито един час.
