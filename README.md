# Салон за красота — демо

Демонстрационен сайт за **измислен** салон за красота в София. Салонът не
съществува. Служи за показване пред потенциални клиенти от бранша, за да видят
какво получават, преди да подпишем договор.

Сайтът е `noindex`, за да не влезе измисленият салон в Google.

## Състояние

**В процес.** Първият комит е двигателят, взет от `wavsy/vet-demo` — логиката на
записването, календарният файл, калкулаторът на цени, асистентът и тестовете.
Съдържанието и дизайнът още са ветеринарните и се пренаписват.

Предстои:

- [ ] Марка: име, лого, тъмна редакторска палитра
- [ ] Съдържание на български и английски
- [ ] Четири направления с ценоразписи · курсове · галерия · екип
- [ ] Записване: направление → майстор → ден и час
- [ ] Снимки CC0
- [ ] Качване на кратък адрес и `/qr` за срещи

## Какво прави двигателят

- **Онлайн записване** до край, с `.ics` файл, който се отваря в календара с
  адрес и напомняне.
- **Калкулатор** на избраните услуги в евро, с левова равностойност за ориентир.
- **Асистент**, който отговаря от данните на сайта. Правилов — без външен модел
  и без разход.
- **Две езикови версии**: `/` български, `/en` английски.

## Работа по проекта

```bash
npm install
npm run dev          # http://localhost:3000

npm test             # модулни тестове
npm run build && npm start
npm run test:e2e     # в браузър, срещу вдигнат сървър
```

`npm run test:e2e` ползва вече инсталирания Chrome — не сваля браузър.

Ако добавите текст само на единия език, `npm test` пада — речниците се сравняват
ключ по ключ.
